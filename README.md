Emilo Social Media Selenium Automation
Project Overview

This project contains automated test scripts for the Emilo Social Media application. The tests cover the following functionalities:

Register a new user

Create a post

View posts

Comment on posts

Like posts

Login

Tests are written in Python using Selenium WebDriver and executed with pytest. Reports are generated in HTML format.

Prerequisites

Python 3.11+ installed

Chrome browser installed

ChromeDriver installed and in PATH

Required Python packages:

pip install -r requirements.txt


Selenium

pytest

pytest-html

python-dotenv

.env file with credentials:

EMAIL=testuser_1758642529337@example.com
PASSWORD=Password123

Running Automated Tests

Activate your virtual environment (if using one):

# Windows
.venv\Scripts\activate

# Mac/Linux
source .venv/bin/activate


Run all tests and generate HTML report:

pytest --html=reports/report.html --self-contained-html


Open the report:

Navigate to reports/report.html in your project folder

Open it in your browser to view test results

Test Execution Order

Tests are ordered so that login runs last to avoid session issues.
Other tests (register, create, view, comment, like) run first.

Adding New Tests

Add a new test function in tests/test_flow.py

Use the driver fixture to get the Selenium WebDriver

Use proper CSS selectors or XPaths for elements

Add assertions to verify functionality

Troubleshooting

ChromeDriver version mismatch: Make sure ChromeDriver matches your Chrome browser version

TimeoutException: Increase WebDriverWait duration or check element selectors

Environment variables not loading: Ensure .env is in the project root and load_dotenv() is called
